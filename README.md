# Tutorial For Local Accounts on amethyst launcher ios
## without need microsoft account that have minecraft 
- first download this app [Here](https://apps.apple.com/th/app/koder-code-editor/id1447489375) this app make your device able to change code or text.

- next download a file [here](https://github.com/manuisgod1231-beep/Local-accounts/releases/download/1/example.json)

- now go on file app find that example.json hold click it and click on Open with select koder app

- now type username that u want for example,  "username" : "misg2733"

- and after set your username go back to file app and change the name form example.json to misg2733.json

- now move that local Account file to Amethyst/account
 
 
why we need to change file name same as username we set?
because it not gonna work if username we set and file name doesn’t match
